# 🍽️ Restaurant Website

A stylish restaurant website created for fun to showcase menu items, dining experiences, and modern web design. This project focuses on building an attractive and user-friendly website that captures the feel of a real restaurant brand.

## 🚀 Features
- Eye-catching homepage design
- Menu showcase section
- About Us / Story section
- Reservation or contact section
- Responsive layout
- Smooth navigation
- Modern and clean styling

## 🛠️ Built With
- HTML5
- CSS
- JavaScript

## 🎯 Purpose
This project was created for fun and to improve front-end development skills by designing a realistic restaurant website with a focus on layout, branding, and user experience.

## ▶️ How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/Ogdirdy/Restaurant-Project-.git
   ```

2. Open the project folder:
   ```bash
   cd Restaurant-Website
   ```

3. Open `restaurant.html` in your browser.
